# Radar crypto

Site personnel : scan quotidien « Cassure journalière » (Donchian 20/10, filtre BTC > moyenne 100 jours) sur les cryptos liquides de Binance.

- `scan.mjs` : le scan, lancé chaque nuit à 00:20 UTC par GitHub Actions (`.github/workflows/scan.yml`).
- `site/index.html` : la page publiée sur GitHub Pages.

Outil d'aide à la décision, pas un conseil en investissement.
